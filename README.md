# Offline Walkie Talkie

یه برنامه ساده و سبک بیسیم آفلاین که با قابلیت وصل شدن وای‌فای و هات‌اسپات محلی به همدیگه بتونن مثل بیسیم ارتباط برقرار کنند، بدون اینترنت. دکمه Push-to-Talk (PTT) برای نگه داشتن و صحبت کردن و رها کردن برای قطع شدن صدا. پشتیبانی از اتصال هم‌زمان چند کاربر و انتخاب کانال و فرکانس. افکت صوتی رادیویی و بازخورد صوتی و تصویری. امکان تست و شبیه‌سازی ارتباط بین دو دستگاه، و ساختار آماده برای خروجی اندروید (Capacitor).
